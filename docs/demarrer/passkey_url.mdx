# Passkey & URL d'announce

<small>Temps moyen de lecture estimé à <h className="v3x-title"><u>__2 minutes__</u></h>.</small>

---

### La Passkey, c'est quoi ?

- La Passkey qui t'es attribuée est ton identité sur V3X.<br/>
Elle est incluse dans ton URL personnelle et sert à t'identifier.

```bash
https://announce.v3x.club/announce/<TA_PASSKEY>
```

:::danger
- Ta passkey est **strictement personnelle**, il ne faut <u>**en aucun cas la partager**</u>.
- Quiconque l'obtient, peut se faire passer pour toi sur V3X.
:::

---

### Où trouver ma Passkey ?

- Pour trouver ta Passkey, il suffit d'aller dans :
> <h className="v3x-title">Profil ▸ Paramètres ▸ Intégrations ▸ Passkey</h>

:::warning
- Assure-toi d'être le seul à pouvoir visionner cette page avant de l'ouvrir.
    - Coupe toute diffusion en direct.
:::

---

### Ma Passkey a fuitée, que faire ?

- Regénère ta Passkey <h className="v3x-title"><u>**le plus rapidement possible**</u></h> :
> <h className="v3x-title">Profil ▸ Paramètres ▸ Intégrations ▸ Passkey ▸ Regénérer</h>

:::note
Tu devras ensuite modifier ton URL d'announce dans ton client torrent pour tous les torrents concernés **OU** les re-télécharger pour pouvoir continuer de les partager.
:::

---

### Plusieurs machines / Double seed, est-ce autorisé ?

- Sur V3X, utiliser plusieurs de <h className="v3x-title">tes propres machines</h> est autorisé <h className="v3x-title">uniquement sur ta passkey personnelle.</h>
- Tu peux seeder depuis plusieurs instances différentes, sur des ip's différentes.
- Tu peux seeder le même torrent sur deux instances différentes.
> Le comptage d'upload étant fait <h className="v3x-title">par machine</h>, chacune a son propre budget.

:::warning
Il est strictement interdit de partager ta passkey avec une autre personne.
:::
